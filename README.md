# Tutorial de Git

## 📝 Sobre o projeto

O **Tutorial de Git** é uma aplicação web desenvolvida com o objetivo de apresentar conceitos fundamentais sobre o Git e o GitHub, abordando temas como instalação, configuração, principais comandos e diferenças entre as duas ferramentas.

Este projeto surgiu como uma proposta pedagógica para colocar em prática os conhecimentos adquiridos em **HTML5 e CSS3**, além de servir como material de apoio para o aprendizado e o aperfeiçoamento dos conhecimentos sobre Git e GitHub.

## 🛠️ Tecnologias utilizadas

As seguintes tecnologias foram utilizadas no desenvolvimento do projeto:

- **HTML5:** estruturação e organização do conteúdo das páginas.
- **CSS3:** estilização dos elementos e definição da apresentação visual do site.

## 📂 Estrutura do projeto

```text
tutorial-git/
├── style/
│   └── style.css
├── index.html
└── README.md
```

### 📄 Descrição dos arquivos

- `index.html`: arquivo principal, responsável pela estrutura e pelo conteúdo da página.
- `style/style.css`: arquivo responsável pela estilização e pelo layout do site.
- `README.md`: documento com informações sobre o projeto.

## 🚀 Como executar o projeto

1. Clone este repositório ou faça o download dos arquivos.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em seu navegador.
4. Explore o conteúdo do tutorial!

## 📚 Aprendizados

O desenvolvimento deste projeto proporciona a oportunidade de praticar a criação de páginas web com HTML5 e CSS3, além de reforçar os conhecimentos sobre Git e GitHub.
